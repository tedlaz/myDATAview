# myDATAview

Εφαρμογή κινητού για **προβολή** των παραστατικών myDATA της ΑΑΔΕ. Κατεβάζει παραστατικά εσόδων και εξόδων, τα εμφανίζει
και βγάζει το συνοπτικό βιβλίο. Δουλεύει αυτόνομα, χωρίς server: τα δεδομένα μένουν στη συσκευή.

**Δεν στέλνει τίποτα στο myDATA.** Κανένας χαρακτηρισμός, καμία ακύρωση, καμία νέα εγγραφή. Τα κλειδιά ΑΑΔΕ μπορούν γενικά και
να στέλνουν, οπότε όλη η επικοινωνία περνά από ένα σημείο (`src/aade/client.ts`) που κάνει μόνο GET.

## Οθόνες

- **Αναλύσεις:** tabs «Πίνακας», «Συνοπτικό» (με κοινό έτος) και «Συναλλασσόμενοι».
- **Συναλλασσόμενοι:** πελάτες και προμηθευτές της εταιρείας, με αναζήτηση, φίλτρο ρόλου και τα παραστατικά καθενός. Η επωνυμία διορθώνεται από την οθόνη του συναλλασσόμενου και δεν αλλάζει από τις επόμενες λήψεις· με «Επαναφορά» επιστρέφει η αρχική.
- **Πίνακας ελέγχου:** σύνολα έτους, γράφημα εσόδων/εξόδων ανά μήνα, ΦΠΑ ανά τρίμηνο, καθαρό κέρδος, πάγια, κορυφαίοι πελάτες και προμηθευτές.
- **Έσοδα / Έξοδα:** λίστα παραστατικών με φίλτρο μήνα και κατάστασης και αναζήτηση επωνυμίας ή ΑΦΜ.
- **Παραστατικό:** στοιχεία, γραμμές, φόροι και χαρακτηρισμοί.
- **Συνοπτικό βιβλίο:** πίνακας με όλες τις στήλες του βιβλίου, ανά μήνα ή τρίμηνο.
- **Λήψη:** tab «Νέα από MARK» με την αυτόματη λήψη, και tab «Αρχική & περίοδοι» με αρχική λήψη, προηγούμενες περιόδους και αλλαγή αρχής.
- Στην κορυφή των κύριων οθονών φαίνεται πάντα η ενεργή εταιρεία· πατώντας την πας στις Εταιρείες.
- **Ρυθμίσεις:** tabs «Εταιρείες» και «Παράμετροι».
- **Εταιρείες:** νέα εταιρεία με σάρωση του QR που δείχνει το myDATA Classifier στα «Βασικά στοιχεία» της, ή χειροκίνητα. Πολλές εταιρείες, με δικά τους κλειδιά ή κλειδιά λογιστή, και περίοδο ΦΠΑ μηνιαία ή τριμηνιαία.
- **Θέμα εμφάνισης:** τα 11 θέματα του myDATA Classifier και «Αυτόματο», που ακολουθεί το κινητό.

## Τι να περιμένεις από τα δεδομένα

- Το συνοπτικό και ο πίνακας μετρούν εξ ορισμού **και τα αχαρακτήριστα**, όπως το βιβλίο του myDATA. Υπάρχει διακόπτης για να μετρούν μόνο τα χαρακτηρισμένα.
- Το καθαρό κέρδος βγαίνει από τα ποσά Ε3, άρα μόνο από χαρακτηρισμένα παραστατικά, όποια θέση κι αν έχει ο διακόπτης.
- Η κατάσταση είναι ό,τι δείχνει το myDATA: χαρακτηρισμένο ή αχαρακτήριστο. Τοπικοί χαρακτηρισμοί άλλης εφαρμογής που δεν έχουν σταλεί δεν φαίνονται.
- «Νέα παραστατικά»: ζητά μόνο ό,τι ανέβηκε μετά το τελευταίο MARK ανά βιβλίο, όποια κι αν είναι η ημερομηνία έκδοσης. Έρχονται έτσι και τα εκπρόθεσμα, οι ακυρώσεις και οι νέοι χαρακτηρισμοί. Το MARK προχωρά μόνο μετά από επιτυχία, οπότε μια αποτυχημένη λήψη δεν χάνει τίποτα.
- Αυτόματη λήψη: ορίζεις ελεύθερα το διάστημα σε ώρες, από 0,25 και πάνω, και βλέπεις αντίστροφη μέτρηση ως την επόμενη λήψη. Το «Νέα παραστατικά» τη μηδενίζει. Όσο η εφαρμογή είναι ανοιχτή γίνεται στην ώρα της. Στο παρασκήνιο την ώρα την ορίζει το σύστημα (ελάχιστο 15 λεπτά, με δίκτυο και αρκετή μπαταρία), και δεν ισχύει στο Expo Go. Για ελάχιστη μπαταρία: κάθε λήψη ζητά μόνο τα νέα από MARK, το Android ομαδοποιεί την εργασία με άλλες, και με ανοιχτή εφαρμογή δεν γίνεται συνεχής έλεγχος. Αν ο χρήστης κλείσει την εφαρμογή με «αναγκαστική διακοπή», σταματά ως το επόμενο άνοιγμα.

## Εγκατάσταση

Η εφαρμογή δεν είναι στο Google Play. Το APK (για κινητά 64-bit) βρίσκεται στα [Releases](https://github.com/tedlaz/myDATAview/releases).

Για αυτόματες ενημερώσεις: βάλε το [Obtainium](https://github.com/ImranR98/Obtainium), πάτα «Add App» και δώσε τη διεύθυνση `https://github.com/tedlaz/myDATAview`.

## Ανάπτυξη

Χρειάζεται Node 26 (τα tests τρέχουν TypeScript απευθείας και χρησιμοποιούν το `node:sqlite`).

```bash
npm install
npm test            # λογική, χωρίς κινητό και χωρίς δίκτυο
npm run typecheck
npx expo start      # σκανάρεις το QR με το Expo Go στο κινητό
```

Το Expo Go πρέπει να υποστηρίζει το ίδιο Expo SDK με το project (δες το `package.json`).

### Δομή

```
src/app/         οθόνες (Expo Router)
src/aade/        client, μόνο GET, και ανάλυση XML
src/book/        ροή λήψης και συνοπτικό βιβλίο
src/store.ts     βάση sqlite
src/secrets.ts   κλειδιά ΑΑΔΕ στο Keystore / Keychain
src/codes.ts     κωδικοί και λεζάντες ΑΑΔΕ
test/            tests, συνθετικά XML και αναμενόμενα αποτελέσματα
```

### Αλλαγές ΑΑΔΕ

Ο κώδικας ανάλυσης μεταφέρθηκε από το [myDATA Classifier](https://github.com/tedlaz/mydata-classifier), αλλά τα δύο projects είναι
**ανεξάρτητα**: διόρθωση ή νέα έκδοση προδιαγραφών στο ένα δεν περνά αυτόματα στο άλλο, και κανένα test δεν το εντοπίζει.
Κάθε αλλαγή της ΑΑΔΕ χρειάζεται χωριστή αλλαγή εδώ (`src/aade/`, `src/codes.ts`).

Το `test/golden.json` παρήχθη από τον Python κώδικα κατά τη μεταφορά και αλλάζει μόνο αν αλλάξει σκόπιμα η συμπεριφορά.

## Έκδοση Android

Το workflow `.github/workflows/android.yml` χτίζει υπογεγραμμένο APK σε tag `v*.*.*` και το επισυνάπτει στο GitHub Release.

Μία φορά, δημιούργησε το κλειδί υπογραφής:

```bash
keytool -genkeypair -v -keystore mydataview.jks -alias mydataview -keyalg RSA -keysize 4096 -validity 10000
base64 -w0 mydataview.jks > mydataview.jks.b64
```

Βάλε στα GitHub Secrets τα `ANDROID_KEYSTORE_BASE64` (το περιεχόμενο του `.b64`), `ANDROID_KEYSTORE_PASSWORD`, `ANDROID_KEY_ALIAS` και
`ANDROID_KEY_PASSWORD`. Κράτα αντίγραφο του `.jks` σε ασφαλές σημείο: χωρίς το ίδιο κλειδί οι χρήστες δεν μπορούν να αναβαθμίσουν. Μην το βάλεις στο git.

Για νέα έκδοση, άλλαξε το `version` στο `app.json`, κάνε commit και push tag `v<version>`.
